# select_catalog

Selecting a new catalog project by providing a list of ideas and their corresponding descriptions, then filtering and ranking them based on user input.

## Requirements

Install the python runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
python main.py
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.py`

## Implemented tasks

- main.py: Implement a function to store and retrieve ideas, including their descriptions and relevance scores.
