# filter_files

Filters files based on a specific type and renames them accordingly.

## Requirements

Install the shell runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
sh main.sh
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.sh`

## Implemented tasks

- main.sh: Implement a shell script that filters files based on a specific type and renames them accordingly. The script should take two command-line arguments: the file path and the file type. It should filter the files, rename them, and return the number of files filtered.
