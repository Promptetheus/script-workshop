# password_length_validator

Password Length Validator: Verifies if a generated password meets the minimum length requirement

## Requirements

Install the lua runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
lua main.lua
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.lua`

## Implemented tasks

- main.lua: Implement a function that takes a password and the required length as inputs, checks if the password is strong enough, and returns a boolean output indicating whether the password meets the requirements or not.
