# biblio_tagger

Automatically assigns relevant keywords to bibliography entries based on provided tags.

## Requirements

Install the ruby runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
ruby main.rb
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.rb`

## Implemented tasks

- main.rb: Implement the main logic of the bibliography auto-tagger, including parsing tags, matching keywords, and assigning relevant tags to bibliography entries.
