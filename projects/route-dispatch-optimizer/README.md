# route_dispatch_optimizer

Optimizes route dispatch times by calculating the most efficient order of deliveries based on distance and traffic patterns.

## Requirements

Install the lua runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
lua main.lua
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.lua`

## Implemented tasks

- main.lua: Implement a function to calculate the most efficient order of deliveries based on distance and traffic patterns.
