# circuit_voltage_drop_calculator

Calculates the voltage drop across a circuit component given its resistance, length, and current.

## Requirements

Install the cmd runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
cmd /c main.cmd
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.cmd`

## Implemented tasks

- main.cmd: Implement the circuit voltage drop calculator logic, taking resistance, length, and current as inputs and outputting the calculated voltage drop.
