# inference-benchmark-filter

Filters inference benchmarks by a specific parameter and displays the results in a sorted list.

## Requirements

Install the javascript runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
node main.js
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.js`

## Implemented tasks

- main.js: Implement the Inference Benchmark Filter functionality, including filtering and sorting benchmarks based on the specified parameter.
