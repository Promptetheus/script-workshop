# daily_water_intake_goal_setter

Calculates daily water intake goal based on age, sex, and weight

## Requirements

Install the javascript runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
node main.js
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.js`

## Implemented tasks

- main.js: Implement a function to calculate daily water intake goal based on age, sex, and weight. The function should take these parameters as inputs and return the recommended daily water intake in ounces.
