# currency_converter_tax

Currency Converter with Tax

## Requirements

Install the ruby runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
ruby main.rb
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.rb`

## Implemented tasks

- main.rb: Implement a Ruby class `CurrencyConverter` that takes `initial_amount`, `currency`, and `tax_rate` as inputs.
Convert the `initial_amount` to the specified `currency` and calculate the converted amount with tax.
Return the converted amount and tax amount as outputs.
