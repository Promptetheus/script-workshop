# dice_roll_validator_perl

Verifies a valid dice roll inputted. A valid roll is a single number between 1 and 6 or a range in the format 'min-max'.

## Requirements

Install the perl runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
perl main.pl
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.pl`

## Implemented tasks

- main.pl: Validate dice roll inputted. A valid roll is a single number between 1 and 6 or a range in the format 'min-max'. If the input is valid, output the roll value; otherwise, output an error message.
