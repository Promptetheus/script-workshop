# font_size_calculator

Calculates the most suitable font size for a given text in a large print document formatter based on the text content and page margins.

## Requirements

Install the cmd runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
cmd /c main.cmd
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.cmd`

## Implemented tasks

- main.cmd: Implement font size calculation logic based on text content and page margins.
