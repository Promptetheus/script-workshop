# fixture-scheduler-notifier-ruby

Sends a notification when a fixture is due for replacement or needs to be inspected

## Requirements

Install the ruby runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
ruby main.rb
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.rb`

## Implemented tasks

- main.rb: Implement a Ruby GUI application that sends notifications when a fixture is due for replacement or needs to be inspected. The application should have a list of fixtures with their due dates and inspection status. The user should be able to add, remove, and update fixtures. The application should also have a scheduling mechanism to notify the user when a fixture is due for replacement or needs to be inspected.
