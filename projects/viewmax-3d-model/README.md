# viewmax_3d_model

Calculates the optimal orientation for a 3D model to view its surface area maximally based on model dimensions and screen resolution.

## Requirements

Install the javascript runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
node main.js
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.js`

## Implemented tasks

- main.js: Implement a function to calculate the surface area of a 3D model given its dimensions. The function should return the surface area as a 2D array representing the model's surface.
