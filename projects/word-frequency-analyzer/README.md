# word-frequency-analyzer

Analyzes the frequency of words in a given text file and prints the top N most frequent words.

## Requirements

shell runtime. No runtime or dependency installation has been performed.
Uses the language's standard facilities; see the source for platform requirements.

## Usage

```text
sh main.sh <file> <n>
```

- file: Path to the text file to analyze.; example: input.txt

- n: The number of top frequent words to display (default is 5).; example: 10

## Expected output

Prints the top N most frequent words along with their frequency.

## Test status and limitations

Experimental AI-generated code. Execution is untested. Syntax checks and independent static QA
are recorded in workshop.json; a QA pass is not an execution test. Handle user data with care.
