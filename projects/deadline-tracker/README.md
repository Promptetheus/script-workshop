# deadline_tracker

A simple script that calculates the number of days, weeks, months, and years until a deadline, given a due date and a start date.

## Requirements

Install the perl runtime. No dependency installation has been performed.
This project is planned to use standard language facilities; inspect source imports before running.

## Run

```text
perl main.pl
```

Supply any command-line arguments required by the source. GUI projects open a desktop window. Review the source before running.

## Project files

- `main.pl`

## Implemented tasks

- main.pl: Implement a function to calculate the difference between two dates in years, months, weeks, and days, and output the results.
